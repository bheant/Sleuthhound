# Changelog

## 0.1.0, November 2026

First public release.

- Local-first storage: an encrypted SQLite database in the browser, with password and recovery-code keys.
- Invite-only accounts on Cloudflare D1, with an admin page.
- Companies House, Hacker News and CSV sources; Reddit waiting for API approval.
- AI review with Claude, ChatGPT or Grok, using the user's own keys.
- Keep or discard workspace with map, connections graph and deadlines.
- Clients page: ideal-client description from an uploaded client list, and lookalike search.
- Apollo and HubSpot through a stateless proxy.
- Installable, with offline support.
